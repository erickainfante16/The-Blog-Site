Tecnologías Frontend

HTML

Es el responsable de estructurar la información de forma correcta para que pueda ser mostrada.

Nació casi junto con internet y, hasta la fecha, solo ha ido mejorando para abarcar más formas de presentación y uso.

¡OJO! HTML no es un lenguaje de programación, es un lenguaje de marcado y estructura de la información, como puede ser XML o JSON.

CSS

Este lenguaje de marcas se utiliza para decirle al navegador cómo debe presentar la información indicada en el archivo HTML.

CSS es el encargado de cómo presentar la información. Es muy importante en el desarrollo web separar la información de la presentación.

JavaScript

El rey de la interactividad. JavaScript es el único lenguaje de programación que puede ser interpretado por nuestro navegador.

Será el encargado de recoger los eventos que produce el usuario al interactuar con nuestra web y de comunicárselos al Backend.

Framework Frontend

Al igual que en el backend, hay multitud de tareas repetitivas para casi cualquier aplicación web. Por eso existen frameworks de frontend que se encargan de manejar estas situaciones para no hacerlas desde cero cada vez.

Hay para todos los gustos: ReactJS, VueJS, Angular, Svelte, Next… Escoge el que más te guste y estúdialo a fondo para tener el control del Front.

Control de versiones: Git y GitHub

Es importante distinguir que Git es la herramienta de línea de comandos que gestiona los repositorios localmente, mientras que plataformas como GitHub, GitLab o Bitbucket son servicios en la nube que alojan estos repositorios para facilitar el almacenamiento centralizado y la colaboración en equipo.

Tecnologías Backend

Lenguajes de servidor: Python, PHP, Java

Este lenguaje será el encargado de llevar toda la lógica de negocio de la aplicación y de interactuar con la base de datos para realizar las peticiones de información necesarias.

También controlará a nivel de permisos si un usuario está autorizado a hacer la acción que intenta, si puede ver dichos datos, etc.

Bases de datos: SQL

Hay dos vertientes muy diferenciadas: los sistemas de bases de datos relacionales, como MariaDB, MySQL o PostgreSQL, y los no relacionales, como MongoDB.

Estas últimas también se llaman bases de datos NoSQL o de clave-valor.
